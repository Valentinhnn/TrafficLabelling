# TrafficLabelling: synthetic network traffic generation from CICIDS2017

Research internship project (GITA research group, summer 2026) on generating **realistic synthetic network flows** to enrich intrusion detection datasets, using the [CICIDS2017](https://www.unb.ca/cic/datasets/ids-2017.html) dataset.

The work has two parts:
1. **Static flow features**: generate individual BENIGN flows whose statistical distributions match the real ones (Gaussian Mixture Model baseline vs CTGAN).
2. **Temporal sequences**: generate sequences of flows between a pair of hosts, with realistic inter-arrival times (bursts / idle periods).

## Results

### Part 1: CTGAN vs GMM on 7 flow features

Fidelity is measured per feature with the Kolmogorov–Smirnov statistic (KS) and the Wasserstein distance normalised by the interquartile range (score, lower is better).

| Feature | Score GMM | Score CTGAN |
|---|---|---|
| Flow Duration | 11.85 | **3.51** |
| Packet Length Mean | 0.29 | **0.13** |
| Flow Bytes/s | 53.44 | **4.25** |
| Flow Packets/s | 14.06 | **0.42** |
| Fwd IAT Mean | 18.28 | **11.01** |
| Bwd IAT Mean | 219.37 | **53.59** |
| Packet Length Std | 1.00 | **0.23** |

CTGAN reproduces the distributions much more closely than the GMM on all 7 features (KS values are of the same order for both, 0.04 to 0.21).

**Downstream check (IDS):** a Random Forest intrusion detector trained on real data only vs real + synthetic data reaches the same performance (F1 0.9515 vs 0.9517, accuracy 0.9802 vs 0.9804): the synthetic flows do not degrade detection.

### Part 2: temporal sequences

- **Key finding:** within a host-pair sequence, the real lag-1 autocorrelation of the 7 features is almost zero (0.02 to 0.05). A first multivariate LSTM invented an artificial autocorrelation (up to 0.44), which is less faithful than no correlation at all.
- **Retained architecture:** features are drawn i.i.d. from a stock of CTGAN-generated flows (keeping the Part 1 fidelity), and only the inter-arrival time (delta_t) is generated by a univariate autoregressive LSTM, the one dimension where a real temporal structure (bursts / idle) is plausible.
- **Results:** feature distributions stay close to the real ones (KS 0.04 to 0.16) and their flow-to-flow correlations stay near zero as in the real data. Inter-arrival times remain the main limitation: the synthetic delta_t is much shorter on average than the real one (54 s vs 1,997 s, KS 0.82), an open point for future work.

Figures: `out_sequences_v2/figures/` and `out_ids_eval/`.

## Approaches tried and set aside

Kept for reference in `annexe_pistes_ecartees/`:
- `lstm_temporal_generation.py`: multivariate LSTM generating features and delta_t together (spurious autocorrelation, see above).
- `hawkes_discrete.py`: modelling flow arrivals as a discrete Hawkes process.

## Repository structure

| File | Role |
|---|---|
| `gan_train_generate.py` | Trains CTGAN on BENIGN flows and generates synthetic flows; compares with the GMM baseline |
| `ids_evaluation.py` | Random Forest IDS evaluation: real vs real + synthetic |
| `temporal_sequences.py` | Sorts flows in time and builds host-pair sequences |
| `sequence_generation_v2.py` | Sequence generation (i.i.d. CTGAN features + LSTM delta_t) and fidelity metrics |
| `generate_report_figures.py` | Report figures |
| `run_pipeline.sh` | End-to-end pipeline for Part 2 (diagnostic, delta_t mode selection, generation, figures) |
| `noise_sweep.sh` | Sensitivity of delta_t generation to the LSTM noise level |
| `build_tableau_excel.py` | Builds the comparative Excel table from `tableau_comparatif.csv` |
| `ctgan_model_mv.pkl`, `out_sequences_v2/lstm_deltat_model.pt` | Trained models |

## Reproducing

1. Download the CICIDS2017 CSV files ("MachineLearningCSV" or "TrafficLabelling" version) from the [Canadian Institute for Cybersecurity](https://www.unb.ca/cic/datasets/ids-2017.html) into `data/` (not included in this repository because of their size).
2. Install the dependencies: `pandas`, `numpy`, `scipy`, `scikit-learn`, `ctgan`, `torch`, `statsmodels`, `matplotlib`, `seaborn`, `openpyxl`.
3. Run each script with `--help` for its options, for example:
   ```bash
   python3 gan_train_generate.py --data-dir data
   python3 ids_evaluation.py --data-dir data
   python3 temporal_sequences.py --data-dir data
   bash run_pipeline.sh
   ```
